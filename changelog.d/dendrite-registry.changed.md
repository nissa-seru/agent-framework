- Agent selection reads declared roles from the registry instead of excluding agent kinds at each site. Residents, the subconscious and conversation forks are selected exactly as before. One difference: an ephemeral agent that is mid-run is no longer queued for untargeted broadcasts (a module's `requestInference: true`, an untargeted channel message or push event, coalescing's default readers) or for host-wide gate wakes. Such requests previously sat in the queue until the run ended and were then dropped with an `agent_not_found` trace; they are now never queued.
- The registry is kept beside the store as two recovery files, `recovery/agent-registry.json` (snapshot) and `recovery/agent-registry-ended.jsonl` (append-only log of ended records), so switching the store's branch doesn't rewind it. A framework given a `store` and no `storePath` keeps it in two Chronicle states instead: `framework/dendrite` (snapshot) and `framework/dendrite/ended` (append log). A registry that can't be read, or isn't in a form the registry reads, refuses `create()`. A change a caller asks for is stored before it takes effect, and the call throws when the write fails.
