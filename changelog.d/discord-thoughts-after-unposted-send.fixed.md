- The Discord module no longer edits a turn's thoughts into a message posted before an attempt to post that posted nothing. It edits a tool turn's thoughts, as a spoiler, into the message the latest `send`, `reply` or speech posted. An attempt that posted nothing (the client threw, or the rate limit or a missing reply context refused it) left the message from before it in place, so the thoughts were edited into a message people may already have read. A `dm`, which posts but can't take the thoughts, did the same. Each of these now forgets the earlier message before it tries to post.
